# 中国地形 · 三维高程地图

单文件、离线可用的中国三维地形可视化页面，使用真实高程数据生成。

- 高清版：2048 × 1536 高程网格
- 轻量版：1536 × 1152 高程网格，加载更快
- 两版页面加载时可直接互相切换

在线查看：https://backtraxe.github.io/china-terrain/

轻量版（1536 网格，首包约 2.6MB gzip）：https://backtraxe.github.io/china-terrain/china-terrain-lite.html

## 内容

- 2048 × 1536 高程网格，约 315 万顶点
- 城市、地标、省界、山峰、河流、湖泊与地理区域标注
- 默认俯视，可一键切换立体视角
- 触屏：单指拖动平移，双指旋转/缩放
- 可点击指北针：一键恢复正北朝上
- 右侧 +/− 缩放按钮，桌面与手机均可用
- 高倍放大仍保留省界，悬停时高亮当前省份
- 平陆运河（2026-09-16 通航，134.2 公里）线路与地名
- 五岳模式与五岳快捷导航
- 搜索支持别名与地理分组（五岳、三山、五湖、四大盆地等）
- 地质地貌图层：断裂、火山、喀斯特、丹霞、雅丹、冰川
- 可调垂直比例，支持 ×1 真实比例
- 剖面、等高线、省名、标签开关、PNG 存图、视角链接分享

## 数据与说明

高程：AWS Terrain Tiles（SRTM / GMTED2010 / ETOPO1），网格约 2.8 km。  
水系与湖泊：Natural Earth 1:10m。省界：DataV.GeoAtlas。  
页面为概览用途，地质与地名标注为概览位置。

## 本地打开

直接打开 `index.html` 即可，无需服务器或网络。
